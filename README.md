# salat-stealer-analysis

Статический разбор Salat Stealer: поддельная сборка zapret, загрузчик на Go, вторая стадия и адреса C2.
Образцы и расшифрованная нагрузка в репозиторий не входят. Код только читает файлы и ничего не запускает.

## Цепочка

1. Архив с `zapret`: все `.bat` заменены на `start DiscordFix.exe`, настоящий `winws.exe` не запускается.
2. `DiscordFix.exe`: Go 1.25, обфускация имён (garble). В `.data` лежит блок 4,9 МБ.
3. Блок расшифровывается RC4 (ключ 16 байт собирается из восьми DWORD цепочечным XOR), затем zlib. Получается PE на 12 309 504 байт.
4. Загрузчик грузит PE в память вручную (`debug/pe`, перенос секций, импорты), на диск не пишет.
5. Вторая стадия: Go 1.24, пакет `salat`. Это стилер и RAT.

## Ключи второй стадии

| Что | Как получается |
|---|---|
| AES-128 ключ | `md5("biba")` и накопительный XOR (`b[k] ^= b[k-1]`) |
| XOR-ключ 26 байт | AES-GCM-запечатанная константа из `main.GetHWID` |
| запись конфигурации | hex, накопительный XOR, XOR-ключ, hex, AES-GCM |

Машинная часть, которую `main.main` подмешивает в XOR-ключ, в `main.dec` накладывается второй раз и сокращается. Поэтому всё считается без данных жертвы.

## Адреса C2

Три таблицы по 129 DWORD в `.rdata`. Каждая преобразуется в число (`main.gb`), затем `c^65537 mod N`, где N 4096 бит строится из четвёртой таблицы. Результат проходит запись конфигурации.

Встроенный блок на 284 КБ оказался набором из 91 корневого сертификата. Среди них один чужой, самоподписанный `CN=Resolver, O=Ebeme`.

## Запуск

```
pip install -r requirements.txt
python -m salatkit.unpack_loader DiscordFix.exe stage2.bin
python -m salatkit.config_keys stage2.bin --out-certs certs.pem
python -m salatkit.endpoints stage2.bin
python -m salatkit.indicators stage2.bin
```

Параметры (адреса таблиц, константы) подходят к сэмплу `83d2faf5...ec1a`. Для другого сэмпла добавьте `LoaderParams` в `KNOWN_SAMPLES` и поправьте адреса в `config_keys.py` и `endpoints.py`.

## Что умеет вторая стадия

По именам функций и строкам:

- Chromium: DPAPI-ключ из `Local State`, App-Bound ключ, куки, логины, автозаполнение, токены. Яндекс: `local_encryptor_data`. Firefox: `key4.db` на чистом Go.
- Обход блокировки базы: перечисление системных хендлов и дублирование хендла файла из процесса браузера.
- Discord, Steam, Telegram `tdata`, кошельки, буфер обмена, скриншоты, кейлоггер, веб-камера, SOCKS5, удалённая оболочка.
- Выгрузка: zip в памяти, JSON, HTTPS с ротацией адресов и встроенным набором сертификатов.
